## 3. กฎใหม่ที่สำคัญที่สุดจากก้อนนี้

> **`lib/server/*` ไม่แปลภาษา — คืนคีย์เท่านั้น หน้าจอเป็นคนแปล**

ผลที่ได้สามอย่าง:

1. ข้อความ error เปลี่ยนภาษาตามปุ่มจริง ไม่ค้างอยู่ในภาษาที่เซิร์ฟเวอร์เลือกตอนนั้น
2. **สคริปต์ smoke ตรวจคีย์ ไม่ตรวจประโยค** — นี่คือรากของบั๊กที่ทำให้เทสต์ 11 เคส
   พังตอนแปลเป็นอังกฤษรอบก่อน จะไม่เกิดอีก
3. `cookies()` ไม่หลุดเข้าไปในชั้นธุรกิจ ซึ่งรันในสคริปต์ที่ไม่มี request context

กฎรองที่ตามมา:

- **พจนานุกรมครบคู่เป็น compile error ไม่ใช่เทสต์** — `vi.ts` เป็นต้นฉบับและ export
  `MessageKey`; `en.ts` ประกาศเป็น `Record<MessageKey, string>` ขาดคีย์ = tsc พัง
  **พิสูจน์แล้วด้วยการลบคีย์ทิ้งหนึ่งตัวแล้วดู `TS2741`** ไม่ได้เชื่อว่ามันทำงาน
- **`countKey()` ให้ชั้นธุรกิจเลือกรูปเอกพจน์/พหูพจน์เอง** เพราะมันเป็นฝ่ายที่รู้จำนวน
  หน้าจอจึงเรียก `t(key, params)` แบบเดียวเสมอ — เลิกเขียน `"5 minute(s)"` ได้แล้ว
- **ห้ามแทรกชื่อฟิลด์เป็น `{label}`** ถ้าชื่อฟิลด์นั้นต้องแปลเอง — `invalidRate()`
  รับคีย์ต่อฟิลด์เข้ามาแทน และ `loadMovableSession()` เอาป้าย source/target
  ไปเป็น**ส่วนหนึ่งของคีย์** เพราะตอนกดรวมบิลผู้ใช้ต้องรู้ว่าบิลไหนที่ติดปัญหา

## 4. เรื่องฟอนต์ — ตรวจแล้วด้วยของจริง

`app/layout.tsx` ขอ Archivo แบบ `subsets: ["latin", "vietnamese"]` และ **ตัด
Noto Sans Thai ออก** (UI ไม่มีภาษาไทยแล้ว)

ตรวจจาก CSS ที่เซิร์ฟเวอร์ส่งออกมาจริง ไม่ใช่เชื่อ option — `@font-face` ที่ emit มี:

```
U+102-103, U+110-111, U+128-129, U+168-169, U+1A0-1A1, U+1AF-1B0,
U+300-301, U+303-304, U+308-309, U+323, U+329, U+1EA0-1EF9, U+20AB
```

ครอบ Ă ă · Đ đ · Ơ ơ · Ư ư · สระประสมทั้งชุด — และ **U+20AB คือสัญลักษณ์ ₫ เอง**
ถ้าไม่ขอ subset นี้ สัญลักษณ์เงินบนทุกหน้าจอจะตกไปใช้ฟอนต์ระบบ

## 5. ตรวจแล้วว่า cookie ภาษาใช้ได้จริง (จาก HTML ที่เซิร์ฟเวอร์ส่งออกมา)

## 9. ค่าเริ่มต้นที่ตกลงไว้สำหรับสาขาเวียดนาม (ยังไม่ได้ลง DB — Task 9)

| ฟิลด์ | ค่า | เหตุผล |
|---|---|---|
| `currency` | `VND` | ไม่มีหน่วยย่อย — `45000` คือ `45.000 ₫` |
| `timezone` | `Asia/Ho_Chi_Minh` | **ลืมง่ายที่สุด** — คุม `branchDayKey()` ทั้งเลขบิลรายวันและ unique key ของเลขคิว |
| `vatRateBp` | `800` (8%) | อัตราลดที่ครอบอาหาร/เครื่องดื่ม · ตรงกับเคสเวียดนามที่มีอยู่แล้วใน `smoke-bill.ts:215` |
| `serviceChargeBp` | `500` (5%) | **จงใจไม่ใช่ 0** — 0 จะลบความต่างระหว่างทานที่ร้านกับซื้อกลับ ซึ่ง `chargesServiceCharge()` มีไว้เพื่อสิ่งนี้ และจะทำให้เทสต์ที่ตรึงเรื่องนี้ไว้กลายเป็นเทสต์เปล่า |
| `pricesIncludeVat` | `false` | เมนูเวียดนามเขียน "giá chưa bao gồm VAT" · และทำให้ได้เดินเส้นทาง "บวกเพิ่ม" ของ `calculateBill()` ซึ่งสาขาตั้งต้นไม่เคยใช้เลย |

**ถ้าอยากได้ราคารวมทุกอย่างในตัวเลขเดียว** ให้พลิก `pricesIncludeVat` เป็น `true`
ฟิลด์เดียว — สูตรรองรับทั้งสองทางอยู่แล้ว

## 10. เครื่องมือระหว่างทาง

สคริปต์แปลงทั้งหมดอยู่ใน scratchpad ของรอบทำงานนี้ (ไม่ได้อยู่ในโปรเจกต์ ตั้งใจ) —
เป็นการแทนที่แบบตรงตัวครั้งเดียวจบ ไม่ใช่เครื่องมือที่ต้องเก็บ

**บทเรียนเรื่องเครื่องมือสองข้อ:**

1. **heredoc ของ Git Bash บน Windows กินแบ็กสแลชในสคริปต์ Node** — regex อย่าง
   `/[.*+?^${}()|[\]\\]/g` พังทันที ต้องเขียนไฟล์ด้วยเครื่องมือเขียนไฟล์แทน
   (และไฟล์ที่มีอักษรเวียดนาม/ไทยก็ควรเขียนแบบเดียวกัน กัน encoding เพี้ยนเงียบ ๆ)
2. **regex `\.error` กวาดโดน `console.error` ไปด้วย 20 ไฟล์** — จับได้เพราะไล่อ่าน
   diff ไม่ใช่เพราะ tsc (มันยัง type-check ผ่าน) · การแทนที่แบบกวาดทั้งโปรเจกต์
   ต้องตามด้วยการอ่านสิ่งที่มันเปลี่ยนจริงเสมอ
